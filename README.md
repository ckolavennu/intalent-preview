# InTalent — independent redesign prototype

Open index.html in Chrome, Edge or Firefox. No npm, server, account or internet connection is needed for the core preview. External article and email links require their usual internet/email services.

Optional local server: `python -m http.server 8000` then open http://localhost:8000. For GitHub Pages, upload the contents of this folder to a repository and publish from the branch root. All assets use relative paths. No build step. A noindex/nofollow meta tag is included for review; it is not privacy/access control. Use a private review arrangement if confidentiality is required.

Design: direction 1 with elements of direction 3 — editorial typography, deep teal, restrained red, service-first navigation. Native HTML/CSS/JS, custom inline SVG line icons, system Arial/Georgia, no dependencies. Reduced-motion support. Six service detail dialogs, responsive navigation, FAQ and a validated local-only enquiry preview. No backend, analytics, cookies or lead transmission.

Content source: https://intalent.my/ (six main service categories, company number, email, office cities, and links to three existing articles). Copy and suggested process are editorial proposals requiring owner approval. No fake testimonials or numeric claims. Contact numbers were omitted because the current website lists inconsistent numbers. Official logo and photography could not be downloaded from this environment; the wordmark is a temporary typographic recreation and images are illustrative crops of AI-generated design mockups, not real InTalent staff. Replace these with authorised original assets before public release. Images are intentionally local for offline testing; their resolution is limited. The prototype is a single-page design, not a migration of all existing pages. Preserve existing URLs, verify service details and contacts, implement secure form delivery and consent, and remove noindex only on approved production deployment. Article links go to the current live site.
